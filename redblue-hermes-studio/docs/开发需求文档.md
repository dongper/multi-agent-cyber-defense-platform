# 红蓝协同智能安全运营平台 — 开发需求文档

> 版本：v1.0 ｜ 代码：`redblue-hermes-studio`（`hermes-web-ui` v0.6.47 红蓝定制版） ｜ 周期：2026-08-24 → 2026-09-01

## 1. 背景与目标

### 1.1 背景

红蓝协同智能安全运营平台是基于 Hermes Studio 定制的红蓝对抗安全运营系统，面向 CTF 与授权安全测试场景。它在 Hermes Agent 多智能体底座上新增「安全运营工作台」，将红队攻击验证与蓝队研判处置放进同一界面，并以**授权边界 + 证据优先**为硬约束。

### 1.2 目标

1. **红蓝协同闭环**：红队（攻击验证 / 证据校验）→ 蓝队（研判 / 溯源 / 处置建议）全链路协作。
2. **证据驱动**：攻击链分析与事件报告只基于真实会话、工具调用与执行记录，拒绝无证据推测。
3. **授权可控**：红队执行仅限带 `AUTHORIZED_SECURITY_TEST` 标记的授权任务。
4. **复用 Hermes 底座**：任务走 Kanban、问答走会话、技能走 CTF Skills、编排同步工作流画布。

## 2. 用户角色

| 角色 | 核心诉求 |
| --- | --- |
| 红队操作员 | 创建授权任务、驱动攻击验证智能体、记录可复核证据 |
| 蓝队分析师 | 告警研判、日志关联、恶意样本分析、攻击路径还原 |
| 安全运营负责人 | 态势总览、事件报告汇总、处置建议与授权边界把控 |

## 3. 功能需求

### 3.1 安全运营工作台（`/security-operations`）

5 个模块：

| 模块 | 需求 |
| --- | --- |
| 态势总览 | 展示实时问答、授权任务、技能调用与智能体运行状态 |
| 任务中心 | 新建 / 编辑授权任务，编排 CTF Skills，保存可追溯问答；授权标记缺失时禁止执行 |
| 智能体编排 | 11 个红蓝智能体拖拽、连线、编辑配置；编排同步到工作流画布 |
| 攻击链分析 | 基于当前任务真实消息 / 工具调用 / 执行记录生成攻击链，无证据不补链 |
| 事件报告 | 汇总真实任务、会话、智能体结果与证据引用，可导出 JSON |

### 3.2 红蓝智能体

- 红队 5 个：任务指挥官、Web 风险验证、二进制分析、密码分析、证据校验。
- 蓝队 6 个：事件指挥官、告警研判、日志关联、恶意样本分析、攻击路径还原、处置建议。
- 每个智能体包含：`systemPrompt`、`role`、`skills`、`steps`（工作步骤）、画布坐标。

### 3.3 CTF 技能

- 10 类 CTF 技能支撑智能体：`ctf-web / pwn / reverse / crypto / forensics / osint / malware / hub / misc / writeup`。

### 3.4 底座能力（复用 Hermes Studio）

- AI 聊天（流式）、可视化工作流、模型 / Profile 管理、群聊、Coding Agents、技能与记忆、语音 / TTS / STT、Web 终端、平台渠道、Kanban、定时任务、用量分析、自动更新。

## 4. 非功能需求

| 维度 | 要求 |
| --- | --- |
| 安全 | 红队执行必须经 `AUTHORIZED_SECURITY_TEST` 授权；处置建议默认不执行生产变更；危险操作需审批 |
| 可信 | 攻击链 / 事件报告证据优先，区分事实 / 假设 / 待确认；未知环节显式标注 |
| 数据 | 复用 Hermes SQLite（会话 / 看板 / 技能统计）；事件报告可导出 JSON |
| 复用 | 不新增 UI 库（Naive UI + Vue Flow）；不新增后端安全逻辑（复用 Kanban / Sessions / Skills / Workflows API） |
| 兼容 | 独立端口运行（前端 8659 / 后端 8657），与联通智能体实例互不影响 |

## 5. 核心业务流程

```text
创建授权任务（Kanban，正文含 AUTHORIZED_SECURITY_TEST）
  → 任务中心问答（runCyberDefenseChat）
  → 红队智能体攻击验证 → 证据校验
  → 蓝队智能体研判 / 日志关联 / 恶意样本分析 / 攻击路径还原
  → 攻击链分析（基于真实会话与工具记录）
  → 事件报告（汇总证据引用）→ 导出
```

## 6. 验收标准（概览）

详细验收见 `docs/SPEC/07-验收标准与风险降级SPEC.md`，最小成功基线：

1. `npm run dev:redblue` 可启动，访问 `/security-operations` 正常。
2. 任务中心可创建授权任务；无授权标记时执行被阻止。
3. 智能体编排可拖拽连线 11 个红蓝智能体，并同步到工作流画布。
4. 攻击链分析只基于真实会话 / 工具记录生成，空白任务不推断。
5. 事件报告可汇总并导出 JSON。
