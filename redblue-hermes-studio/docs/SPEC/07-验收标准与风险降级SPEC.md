# 07-验收标准与风险降级 SPEC

## 1. 环境验收

| 项 | 标准 |
| --- | --- |
| 启动 | `npm run dev:redblue` 可启动（前端 8659 / 后端 8657） |
| 入口 | 访问 `http://127.0.0.1:8659/#/security-operations` 正常 |
| 隔离 | 与联通智能体实例端口 / 数据互不影响 |

## 2. 授权边界验收（硬约束）

| 项 | 标准 |
| --- | --- |
| 授权拦截 | 任务正文不含 `AUTHORIZED_SECURITY_TEST` 时，执行按钮禁用、不发起执行 |
| 授权通过 | 含标记的任务可正常执行问答 |

## 3. 任务中心验收

| 项 | 标准 |
| --- | --- |
| 创建 | 可新建 / 编辑授权任务 |
| 编排 | 可为任务编排 CTF Skills |
| 问答 | 任务内问答可追溯（真实会话） |

## 4. 智能体编排验收

| 项 | 标准 |
| --- | --- |
| 数量 | 11 个红蓝智能体（5 红 + 6 蓝） |
| 交互 | 可新建、编辑、拖拽、连线 |
| 同步 | 编排同步到工作流画布 |

## 5. 攻击链 / 报告验收

| 项 | 标准 |
| --- | --- |
| 证据优先 | 攻击链只基于真实消息 / 工具调用 / 执行记录生成 |
| 空态 | 空白任务显示空态，不推断补链 |
| 报告 | 事件报告汇总任务 / 会话 / 结果 / 证据引用 |
| 导出 | 可下载 `{taskId}-incident-report.json` |

## 6. 红蓝链路验收

| 项 | 标准 |
| --- | --- |
| 主链路 | 授权任务 → 红队验证 → 证据校验 → 蓝队研判 → 处置建议 |
| 智能体结论 | 结论可复核，区分事实 / 假设 / 待确认 |

## 7. 风险与降级

| 风险 | 降级 |
| --- | --- |
| 底座 Hermes 运行时版本不匹配 | `runtime-config.mjs` 重 pin，切换已装版本 |
| CTF 技能缺失 | 智能体降级为通用分析（保留 systemPrompt 约束） |
| 授权任务数据缺失 | 攻击链 / 报告显示空态，不推断 |
| 编排同步工作流失败 | 本地画布仍可用，提示同步失败 |
| 模型 Provider 不可用 | 切换 OpenAI-compatible；禁用时明确提示 |
| 会话 / 工具记录为空 | 攻击链、报告空态兜底 |
| 期内时间不足 | 保「授权任务 + 授权拦截 + 红蓝主链路 + 攻击链 + 报告导出」 |

## 8. Demo 演示路径（5 分钟）

1. 启动 `dev:redblue`，打开态势总览。
2. 创建授权任务（含 `AUTHORIZED_SECURITY_TEST`）。
3. 任务内问答（红蓝智能体参与）。
4. 展示智能体编排（11 智能体 + 连线，同步工作流）。
5. 展示攻击链分析（基于真实会话 / 工具记录）。
6. 导出事件报告 JSON。
7. 说明授权边界：无标记任务无法执行。

## 9. 最小可交付版本

时间非常紧时必须保留：授权任务 + 授权拦截 + 红蓝主链路智能体 + 攻击链（真实数据）+ 报告导出。
