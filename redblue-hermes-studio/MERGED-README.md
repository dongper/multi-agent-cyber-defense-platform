# 红蓝协同智能安全运营平台

这是一个独立副本，原 `redblue-loop-demo` 和 `hermes-studio` 项目均未被覆盖。

## 本地启动

在本目录执行：

```bash
npm run dev:redblue
```

然后访问：

```text
http://127.0.0.1:8659/#/security-operations
```

若尚未登录，请使用当前配置的本地账号登录。

## 已合并内容

- 红蓝队态势总览、任务中心、智能体编排、攻击链分析、事件报告
- 11 个可新建、编辑、拖拽和连线的红蓝队智能体
- 智能体编排同步到工作流画布
- 真实会话、问答、工具调用和 Skill 使用统计
- 经授权任务的真实执行会话与执行结果
- 基于真实会话数据生成攻击链和事件报告

## 安全边界

红队执行只面向明确授权的安全测试任务。任务正文需包含 `AUTHORIZED_SECURITY_TEST`，否则界面不会发起执行。
