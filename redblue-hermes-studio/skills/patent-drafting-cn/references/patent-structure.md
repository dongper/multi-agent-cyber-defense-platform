# 中国发明专利技术交底书模板结构

## 表格字段说明（第一部分：技术方案说明）

| 行号 | 字段 | 说明 |
|---|---|---|
| 0 | 提案名称 | 专利名称，格式："一种基于XXX的YYY方法/系统" |
| 1 | 申报单位 / 技术联系人 | 申请单位和联系人 |
| 2 | 是否发表过文章 | 必须标注，影响新颖性判定 |
| 3 | 技术背景 | 现有技术描述 + 最相近实现方案 + 其不足 |
| 4 | 现有技术缺点 / 发明目的 | 缺点和目的必须一一对应 |
| 5 | 技术方案详细阐述 | **核心部分**，需含步骤、公式、数据结构、实施例、附图说明 |
| 6 | 关键点和保护点 | 3-4个，不得包含已被现有技术公开的内容 |
| 7 | 替代方案 | 扩大保护范围，防止绕过 |
| 8 | 落地可能性 | 应用计划 + 技术可行性分析 |

## 表格字段说明（第二部分：检索报告）

| 行号 | 字段 | 说明 |
|---|---|---|
| 0 | 提案名称 | 同第一部分 |
| 2 | 检索关键词 | 至少3个，第一个为独立关键词 |
| 3 | 检索结果明细 | 专利号/申请号 + 名称，至少3条 |
| 4 | 最相关的专利文献分析 | 名称、专利号、技术方案、与本发明异同 |
| 6 | 公共搜索引擎关键词 | 至少3个 |
| 7 | 搜索结果明细 | 篇名 + 主要内容 |
| 8 | 与最接近现有技术对比分析 | 逐项对比异同 |

## 撰写要点

1. **新颖性**：交底书中描述的发明必须是全球范围内未公开的
2. **现有技术缺点 vs 发明目的**：每个缺点必须对应一个发明目的，数量一致
3. **技术方案**：必须给出至少一个完整可实施方案，不能只有原理描述
4. **附图要求**：方框图、黑白方式，每个图必须有对应文字描述
5. **软件/方法类专利**：必须提供流程图、系统结构图和系统装置
6. **避免广告用语**：不得用"领先""首创"等宣传性词汇
7. **避免笼统表述**："提高效率""降低成本"太笼统，需具体到技术方案内容
