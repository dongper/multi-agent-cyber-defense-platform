# Multi-Agent Cyber Defense Platform

基于多智能体(Multi-Agent)协同架构的全链路网络威胁一体化防护平台。

通过自主决策、专业分工的智能体集群,实现对复杂网络威胁的主动感知、智能研判与联动响应。

## 项目目标

- **主动感知**: 多源威胁情报采集与融合,实时发现潜在网络威胁
- **智能研判**: 多智能体协同分析,对威胁进行分级、归因与影响评估
- **联动响应**: 根据研判结果自动编排防御策略,实现快速联动处置
