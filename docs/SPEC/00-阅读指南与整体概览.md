# 00-阅读指南与整体概览

## 1. 本版本定位

这是「联通智能体」的 **Hermes Studio 定制版 SPEC**，即 `hermes-web-ui` v0.6.47 的联通定制分支。

目标形态：一个可自托管、多端分发的多智能体 AI 平台 —— 桌面应用（Electron）、本地运行时（Python / Hermes Agent）与 Web 控制台（Vue + Koa），并额外扩展 **Ekko 智能体运行时** 与 **ESP32-C3 智能语音硬件**。

```text
联通智能体
├── packages/client        Vue 3 前端（控制台 / 聊天 / 工作流）
├── packages/server        Koa 后端（API / Socket.IO / SQLite）
├── packages/desktop       Electron 桌面 + 内置 Hermes 运行时
├── packages/ekko-agent    Ekko 智能体运行时
├── packages/esp32-c3      智能语音硬件固件（v1/v2）
└── packages/skills        技能包（图像 / 视频生成）
```

## 3. 一句话定位

联通智能体是一个可自托管的多智能体 AI 平台，通过桌面应用 + Web 控制台 + 本地运行时，整合 Hermes Agent、Ekko Agent 与 Coding Agents，并接入 ESP32-C3 智能语音硬件，覆盖对话、工作流、模型管理、网页浏览与语音交互。

## 4. 本期核心目标

业务闭环：

```text
用户输入（文本 / 语音 / 图片）
  → 前端 → Koa 后端 → Agent 运行时（Hermes / Ekko / Coding）
  → 工具调用（浏览器 / 终端 / 文件 / 设备 / 编码代理）
  → 流式回传 → 前端渲染 → SQLite 落库
```

硬件闭环：

```text
ESP32-C3 配网 → 发现配对（配对码）→ 语音上行（ADPCM）→ STT
  → Agent 处理 → TTS → 设备播放；固件 OTA
```

## 5. 用户角色与核心场景

| 角色 | 想看什么 | 业务价值 |
| --- | --- | --- |
| 终端用户 | 与 Agent 流式对话、工具调用轨迹、生成文件预览 | 高效完成问答 / 任务 |
| 开发者 / 管理员 | Profile / Provider / 模型 / 凭证 / 记忆 / 技能 / 日志 | 统一管理 Agent 环境 |

| 硬件使用者 | 语音对话、设备配网与状态 | 免屏语音交互 |

## 7. 技术栈

Vue 3 · TypeScript · Vite · Koa · Socket.IO · SQLite · Electron · Python（Hermes runtime）· PlatformIO（ESP32-C3）· Vitest / Playwright。

## 8. 最小成功标准

1. `npm run dev` / 桌面应用能启动并打开控制台。
2. 聊天可流式对话，工具调用轨迹可见，会话可持久化。
3. 一个可视化工作流可编排并执行。
4. 模型 / Provider / Profile 可配置，凭证安全存储。
5. 至少一个平台渠道可绑定收发消息。
6. TTS / STT 可用；ESP32-C3 可配网、语音交互、OTA。
7. 重启后会话与配置仍在。

## 9. Demo 成功线

5 分钟内跑通：

1. 打开桌面 / Web 控制台。
2. 展示 Agent / 模型 / 设备状态。
3. 流式对话并展示一次工具调用轨迹。
4. 展示一个可视化工作流。
5. 配置一个模型 Provider。
6. 展示 TTS / STT。
7. 展示 ESP32-C3 设备配对与语音交互（或录制演示）。

## 10. 本期不要做

1. 不上云托管（本地优先，自托管可选）。
2. 不改写上游 Hermes Agent 源码（Studio 定制独立于上游）。
3. 不做多租户复杂权限体系。
4. 不做消息队列。
5. 不新增 UI 库（沿用 Naive UI）。
6. 不让前端接触模型凭证 / Token / AI Key。
