# 01-交付范围分层 SPEC

## 1. 分层原则

| 层级 | 定义 |
| --- | --- |
| 核心必交付 | 期内必须完成，缺失导致 Demo 不成立 |
| 增强交付 | 期内尽量完成，显著提升完整度 |
| 冲刺交付 | 有余力时补齐 |
| 明确不做 | 本期不做，避免失控 |

## 2. 核心必交付

核心必交付按「主链路优先」，不按页面数量平均推进。

| 功能 | 为什么核心 | Owner | 降级 |
| --- | --- | --- | --- |
| 本地 / 桌面启动 | 用户打开即可用 | E | 手动 `npm run dev` |
| 环境 / 状态检查 | 暴露问题所在 | B | 页面显示配置缺失 |
| 流式聊天 | 核心交互 | B/C | 非流式兜底 |
| 会话持久化 | 会话可恢复 | B | 仅内存态（不可接受） |
| 工具调用轨迹 | Agent 可信度 | A/C | 仅展示结果 |
| 模型 / Provider / Profile 配置 | Agent 可运行的前提 | B | 默认单一 Provider |
| 凭证安全存储 | 密钥不下前端 | B | 明确拒绝降级 |
| 一个可视化工作流 | 编排价值 | B | 只读展示 |
| 一个平台渠道 | 多平台价值 | B | 仅单渠道 |
| TTS / STT | 语音价值 | C/B | 仅文本 |
| Ekko Agent 基础运行时 | 定制核心 | C | 复用 Hermes 单智能体 |
| ESP32-C3 配网 + 语音交互 | 硬件亮点 | D | 录制演示兜底 |
| 固件 OTA | 硬件可升级 | D | 本地 USB 烧录 |

## 3. 增强交付

| 功能 | 价值 | 降级 |
| --- | --- | --- |
| 群聊多智能体 | 协作价值 | 单聊 |
| Coding Agents 接入 | 编码代理价值 | 手动 CLI |
| 桌面 Agent 浏览器 | 网页操作价值 | 仅文本回答 |
| 实时语音（VAD） | 语音体验 | 按键触发 |
| 定时任务 / Kanban | 自动化价值 | 手动执行 |
| 用量分析 | 可观测性 | 无 |
| 技能包（图像 / 视频） | 内容生成 | 无 |
| 自动更新 | 分发体验 | 手动下载 |

## 4. 冲刺交付

| 功能 | 说明 |
| --- | --- |
| 设备远程中继 | 非局域网访问设备 |
| 多语音提供商切换 | 本期单提供商可用即可 |
| 工作流可移植性 / 证据 | 跨环境导出 |
| 性能监控面板 | 只读监控 |

## 5. 明确不做

| 功能 | 原因 |
| --- | --- |
| 云服务器托管 | 本地优先 |
| 改写上游 Hermes Agent 源码 | 保持上游可 `hermes update` |
| 复杂多租户权限 | 本地 / 单用户场景 |
| 消息队列 | 期内不需要 |
| 新 UI 组件库 | 沿用 Naive UI |

## 6. Demo 必须保留的闭环

1. 启动桌面 / Web 控制台。
2. 流式对话 + 一次工具调用轨迹。
3. 展示一个可视化工作流。
4. 配置一个模型 Provider（凭证安全）。
5. 展示 TTS / STT。
6. 展示 ESP32-C3 设备配对 + 语音交互。
7. 重启后会话与配置仍在。

若时间紧，优先保「聊天 + 工具轨迹 + 会话持久化 + 模型配置」闭环；硬件部分用录制演示兜底。
