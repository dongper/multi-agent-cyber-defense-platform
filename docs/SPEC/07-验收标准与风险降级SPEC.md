## 9. 风险与降级

| 风险 | 降级 |
| --- | --- |
| 上游 Hermes 运行时版本不匹配 | `runtime-config.mjs` 重 pin；`runtime-versions` 切换已装版本 |
| 模型 Provider 不可用 | 切换 OpenAI-compatible Provider；禁用时明确提示 |
| AI 超时 | 超时不阻塞页面，返回错误态 |
| 设备离线 / 断连 | 页面显示离线态；断连重连 |
| 固件烧录失败 | 本地 USB 烧录（`mcu:v2:flash:clean`）兜底 |
| 语音不可用 | 文本交互兜底；演示用录制 |
| SQLite 初始化失败 | 提示重跑 setup / 重建状态目录 |
| 平台渠道限流 | 显示绑定状态与错误原因 |
| 期内时间不足 | 保「启动 + 流式聊天 + 会话持久化 + 工具轨迹 + 模型配置」主链路 |

## 10. Demo 演示路径（5 分钟）

1. 启动桌面 / Web 控制台。
2. 展示 Agent / 模型 / 设备状态。
3. 流式对话 + 一次工具调用轨迹。
4. 展示一个可视化工作流。
5. 配置一个模型 Provider（凭证安全）。
6. 展示 TTS / STT。
7. 展示 ESP32-C3 设备配对 + 语音交互（或录制演示）。
8. 重启，说明会话与配置已本地持久化。

## 11. 最小可交付版本

时间非常紧时必须保留：

1. 控制台可启动打开。
2. 流式聊天 + 工具调用轨迹。
3. 会话可持久化。
4. 模型 / Provider 可配置且凭证安全。
5. TTS / STT 可用（或录制演示兜底）。
